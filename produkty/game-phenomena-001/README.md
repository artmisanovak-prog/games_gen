# GAME PHENOMENA 001

**Ukázkový datový balíček herních jevů z projektu games_gen.**

- Verze: 0.1.0
- Stav: prototyp / kurátorovaná ukázka
- Počet záznamů: 10
- Jazyk: čeština
- Formát: JSON

## Co to je

Kolekce popisuje neobvyklé události, které mění pravidla herního světa. Každý záznam popisuje výchozí jev, spouštěč, proměnu prostředí nebo postavy, možnosti hráče, možné následky a pravidlo, podle kterého lze situaci dále rozvíjet.

Není to hotová hra ani programovací knihovna. Je to obsahový materiál, který může herní designér použít jako inspiraci při návrhu úkolů, hádanek, postav a interaktivních prostředí.

## Obsah verze 0.1

Deset ukázkových jevů: voda, která si přivlastní píseň; páv s proměnlivým počtem očí; chameleon bez vlastní podoby; zajíc s předčasnou stopou požáru; kocour, který spolkl konec věty; místnost, která si pamatuje hráče; předbíhající stín; výměna způsobu vidění; komín bez správného adresáta; a ticho, které mění proud.

Jde o demonstrační výběr, nikoli o slíbenou finální kolekci 100 položek. Další záznamy mají vznikat až po ověření struktury a použitelnosti.

## Jak to použít

1. Otevři katalog přes GitHub Pages.
2. Prohlédni si jednotlivé jevy a jejich možné herní použití.
3. Stáhni dataset.json, pokud chceš data dále zpracovat.
4. Herní studio může vybrané jevy upravit pro vlastní svět a herní pravidla podle sjednané licence.

## Původ a metodika

Ukázka vychází z principů nástrojů v repozitáři games_gen, zejména Ryba (zvuk jako zásah do prostředí), Myš (přehlédnutý jev a jeho následky), Chameleon (adaptace a odrazy), Kozel (výměna perspektivy) a Netopýr (proměna režimu vnímání). Záznamy byly nově formulovány jako návrhy herních situací. Nejsou automaticky exportovány z lokální historie generátorů.

## Omezení

- Záznamy jsou návrhy, nikoli hotové implementace.
- Možné následky nejsou zárukou vyvážené nebo zábavné herní mechaniky.
- Před použitím v komerční hře je vhodné provést herní test a kontrolu konzistence.
- Ukázka zatím neobsahuje ilustrace ani zvukové soubory.
