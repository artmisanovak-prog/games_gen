# games_gen

Repozitář herních generátorů založených na narativních operacích z pohádek a dalších textů.

## Generátory

### Myš · generátor herních aktů
Generuje vyšetřování anomálií, questové řetězce, rozhodovací situace a události měnící svět. Vychází z pohádky **O myši a o tom, co se stane, když si jí nevšimneš**.

- [Spustit generátor – GitHub Pages](https://artmisanovak-prog.github.io/games_gen/doma/mys/)
- [Zdrojový HTML soubor](doma/mys/index.html)

## Struktura

- `doma/` – pracovní prostor a obsah generátorů.
- `doma/mys/` – první samostatný generátor.

## Poznámka k provozu

Generátor Myš funguje lokálně v prohlížeči, bez serveru a bez AI API. Historii ukládá do místního úložiště daného prohlížeče; záznamy lze exportovat do JSON. Při použití jiného zařízení nebo prohlížeče se místní historie automaticky nepřenáší.
