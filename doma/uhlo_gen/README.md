# ÚHLO_GEN · pracovní nástroje MOUSE

Offline-first sada pro práci s významem jako s polárním vztažným prostorem. Není to detektor chyb ani automatický generátor interpretací. Myš už zaznamenané jevy znovu nediagnostikuje a nesoudí.

## Postup
1. **Rozklad**: vlož zdrojový materiál a odvoď perspektivy, které jsou pro jeho význam skutečně relevantní. Počet ani názvy nejsou pevně dané.
2. **Polární mapa**: každé perspektivě přiřaď směr, vrstvu a vzdálenost od referenční konfigurace.
3. **Vztahy**: popiš, jak se perspektivy a jejich vrstvy ovlivňují. Podobnost sama o sobě není vztahový mechanismus.
4. **Nové vidění**: zapiš, co se ukázalo až díky konkrétnímu uspořádání a o jaké vztahy se postřeh opírá.

Dvanáct úhlů je jedna referenční konfigurace, nikoli povinná taxonomie. Úhel není kategorie, vrstva není synonymum perspektivy a vzdálenost od středu není skóre chyby ani kvality.

Nástroje nic automaticky nevyhodnocují jako chybu a samy netvrdí, že objevily nový význam. Pomáhají materiál rozložit, prostorově uspořádat a dohledat vztahy, z nichž může nové pozorování vzniknout.

Vše běží lokálně v prohlížeči. Stav se ukládá do localStorage; export/import JSON přenáší práci mezi zařízeními. Žádná data se neposílají na server.
