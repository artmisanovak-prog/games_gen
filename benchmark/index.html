BENCHMARK

Generátor kontrolovaných testovacích úloh odvozených od konkrétních karet. Každá úloha má zadání pro model, předem známé řešení a automatické vyhodnocení.

offline-first · bez API · export JSON

01 / Vyber kartu

Každá karta vytváří jiný druh testu. Nejde o převlečené otázky se stejnou logikou.

Stejná karta + stejný seed + stejný počet úloh vytvoří stejnou sadu. Seed je součástí exportu, takže lze experiment zopakovat.

02 / Vygenerovaná sada

Zatím nebyla vytvořena žádná sada.

čeká

Vyber kartu a spusť generování.

03 / Otestuj model

Zkopíruj zadání výše do modelu. Jeho odpověď vlož sem jako JSON. Model nedostává řešení ani hodnoticí klíč.
